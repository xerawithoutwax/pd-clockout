# PD칼퇴도우미 — GitHub 모바일 빌드 패키지

이 패키지는 휴대폰에서 GitHub를 처음 사용하는 경우를 기준으로 파일 업로드 수를 최소화한 버전입니다.

- `PDClockout-source-v0.1.0.zip`: Android 프로젝트 전체 소스
- `android-debug.yml`: GitHub Actions 빌드 설정
- `모바일에서_빌드하는법.txt`: 클릭 순서 안내

GitHub 저장소에는 소스 ZIP을 루트에 올리고, workflow 내용은 `.github/workflows/android-debug.yml` 경로로 생성합니다.
